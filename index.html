Walking

  • WASD / arrows — walk · Shift — run
  • Click / tap — walk there · double-click — run there
  • Hold the button or a finger — walk towards the pointer
  • Q / E, right-drag, two-finger twist — turn the view
  • Wheel, pinch, + / − — zoom
  • M — sound · H — hide the interface
  • Gamepad: left stick, right stick, bumpers, triggers
